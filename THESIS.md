# THESIS – Personant

*Why this project has the shape it has*

---

## The thesis

**An assistant without a past cannot be a partner. Memory must be continuous — and it must be owned
by something that does not forget.**

Today's assistants live in sessions. Each conversation starts from zero, and long ones are compacted
until what mattered is gone. Whatever the model learned about the work, the person, or the last
project was never kept.

Handing memory to the model does not fix this; it relocates the loss. A model rewrites what it
remembers every time it touches it. The record has to live in deterministic, inspectable state, with
the model in narrow judgment roles over it and with a process for validating and improving the quality
of those judgments.

**The best use of AI *by* humans is use of AI *with* humans.** The aim is a partner with
one continuous career.

## What follows

**Career memory and behavior memory are different things.** What the agent has done and how each
project works is career memory; it is scoped and it informs. How the agent thinks and acts is
behavior memory; it is universal. Nothing learned in a project changes behavior without the human's
acknowledgement — projects differ in how the work is done, never in who does it.

**The work's artifacts are not the memory.** What personant helps produce lives in the user's
workspace and belongs to the work.
