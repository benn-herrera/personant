### 8.2 Configuration sources and precedence

Personant reads three kinds of configuration: its own settings ([§8.2.2](8.2.2-personant-settings-config-personant-config-toml.md)), directives ([§8.2.4](8.2.4-directive-precedence.md)) and
the environment ([§8.2.3](8.2.3-environment-variables.md)). opencode's configuration is read by opencode as it is; Personant writes
only the entries named in [§8.1](../8.1-first-run-scaffolding-personant-init/index.md).
