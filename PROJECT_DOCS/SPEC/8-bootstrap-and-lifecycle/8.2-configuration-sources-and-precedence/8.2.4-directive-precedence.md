#### 8.2.4 Directive precedence

Detailed in [§2.6](../../2-data-model/2.6-directive-file-format-directives-md/index.md). Briefly: `directives/defaults.md` < `directives/user.md` <
`directives/prj_<n>/project.md`. The runtime walks the precedence chain at parameter-read time and
returns the first match.
