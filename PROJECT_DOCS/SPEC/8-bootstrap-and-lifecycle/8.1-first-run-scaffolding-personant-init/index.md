### 8.1 First-run scaffolding (`personant init`)

Idempotent. Creates the directory layout from [§2.1](../../2-data-model/2.1-storage-layout/index.md); runs `git init`; writes seed
`directives/defaults.md` and `README.md`; writes Personant's configuration file under
`~/.config/personant/` ([§8.2.2](../8.2-configuration-sources-and-precedence/8.2.2-personant-settings-config-personant-config-toml.md)) as a template with a commented-out example block.
