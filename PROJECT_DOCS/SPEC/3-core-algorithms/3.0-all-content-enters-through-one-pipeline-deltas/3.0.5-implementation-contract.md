#### 3.0.5 Implementation contract

Every delta reaches the composed request only through the [§3.0](index.md) pipeline; there is no bypass. Content the composer assembles from memory already held ([§3.0.1](3.0.1-the-delta-taxonomy.md)) and the opencode-content slots, rebuilt from opencode's input on every request ([§1.3](../../1-operating-model/1.3-opencode-content-in-composed-requests.md)), are not deltas.
