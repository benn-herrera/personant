#### Durability

Content is durable to ≤1 turn at all times; the in-flight turn's prompt and response are
recoverable from the moment the prompt is journaled; a failed journal write aborts the turn ([§4.5.8](../../4-user-surface/4.5-project-identity-and-the-project-s-directory/4.5.8-startup-recovery-after-unclean-shutdown.md) (7)). [§4.5.8](../../4-user-surface/4.5-project-identity-and-the-project-s-directory/4.5.8-startup-recovery-after-unclean-shutdown.md) governs crash recovery.
