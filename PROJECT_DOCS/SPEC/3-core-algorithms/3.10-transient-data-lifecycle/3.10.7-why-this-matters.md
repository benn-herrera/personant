#### 3.10.7 Why this matters

Without this lifecycle, every path or URL in a `tool.result` would inflate `history_symbols`, raise
Jaccard's denominator, and degrade [§3.4](../3.4-recall-matching/index.md) precision, compounding over a [§9.1](../../9-measurement-and-validation-regime/9.1-the-four-month-simulation-v0-1-acceptance-gate/index.md) simulation. It is a
prerequisite for a meaningful recall-fidelity measurement ([§9](../../9-measurement-and-validation-regime/index.md)).
