### 3.6 Fallback dissection

Budget-pressure trigger (`dissect.pressure-threshold`, [§2.6.1](../2-data-model/2.6-directive-file-format-directives-md/2.6.1-recognized-parameters.md)) → the **clusterer** (the model call that groups the oldest content into
threads to close, [§5.3](../5-model-interaction/5.3-clusterer-prompt-for-fallback-clustering.md)) clusters the oldest content → batch close → ack flow.

The grouping is best effort: under stress, thread quality degrades gracefully; content is not lost.
