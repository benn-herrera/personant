### 3.8 Deep cold archival

Threads are archived off-spine under spine cardinality pressure and recovered by explicit fetch,
using the autonomic git layer ([§8.3](../../8-bootstrap-and-lifecycle/8.3-substrate-validation-in-autonomic-git-operations/index.md)) rather than a bespoke archive format.
