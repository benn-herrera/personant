#### 4.5.1 Active project root

The active project is resolved from opencode's session directory ([§4.5.7](4.5.7-project-bootstrap-at-startup.md)) unless the user selects
one explicitly. The active project root is that project's `current_root_path` ([§2.5.1](../../2-data-model/2.5-project-metadata-schema/2.5.1-canonical-projects-prj-n-meta-json.md)): after an
explicit switch it is the selected project's root, not the session directory. The active project
selects the project-scoped directives ([§2.5](../../2-data-model/2.5-project-metadata-schema/index.md), [§2.6](../../2-data-model/2.6-directive-file-format-directives-md/index.md)). A directory change inside a command
the agent or user runs does not change the active project.
