#### 4.5.3 Resolving a directory to a project

Given a directory (opencode's project directory, [§4.5.1](4.5.1-active-project-directory.md)), the project is the known project
whose `current_root_path` is that directory; if there is none, a new project is created rooted there
and named for the directory's base name ([§4.5.2](4.5.2-two-levels-of-project-identity.md)). Personant reads nothing inside the directory, its git included.

The active project does not change when a command inside the session changes its own working
directory.
