#### 4.5.7 Project resolution at startup

When an opencode session starts, the active project is resolved from its project directory
([§4.5.1](4.5.1-active-project-directory.md)), first hit wins:

1. **Directory path match.** The known project whose `current_root_path` is the directory.
2. **Create.** Otherwise a new project rooted at the directory, named for its base name
   ([§4.5.3](4.5.3-resolving-a-directory-to-a-project.md)).
3. **No directory.** When no directory is given, `prj_default`.

`prj_default` is always available as the no-project default.
