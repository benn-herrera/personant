#### 4.5.7 Project resolution at startup

When an opencode session starts, the active project is resolved from its project directory
([§4.5.1](4.5.1-active-project-directory.md)). No directory given: `prj_default`. Otherwise:

1. the project whose directory it is (the known project whose `current_root_path` is the directory);
2. else a new project for it, named for its base name
   ([§4.5.3](4.5.3-resolving-a-directory-to-a-project.md)).

`prj_default` is always available as the no-project default.
