#### 4.5.1 Active project directory

The active project is resolved from opencode's project directory ([§4.5.7](4.5.7-project-resolution-at-startup.md)). The active
project's directory is that project's `current_root_path` ([§2.5.1](../../2-data-model/2.5-project-metadata-schema/2.5.1-authoritative-projects-prj-n-meta-json.md)). The active project
selects the project-scoped directives ([§2.5](../../2-data-model/2.5-project-metadata-schema/index.md), [§2.6](../../2-data-model/2.6-directive-file-format-directives-md/index.md)). A directory change inside a command
the agent or user runs does not change the active project.
