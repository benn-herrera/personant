#### 4.5.2 Two levels of project identity

A project is one directory and a bundle of threads. Its identity has two levels (schema: [§2.5.1](../../2-data-model/2.5-project-metadata-schema/2.5.1-authoritative-projects-prj-n-meta-json.md)):

| Level | Form | Stable? |
|---|---|---|
| Internal handle | `prj_<n>` | yes — assigned at creation, never changes; storage layout key, thread registry reference key |
| Display name | the project's directory's base name at creation | yes — set at creation |

A directory Personant has not seen is a new project, whether or not it was moved: Personant cannot
tell a move from a copy, or from several copies, and people routinely copy old projects as
templates for new ones.
