### 1.2 MCP

opencode delivers all MCP content: server instructions, tool definitions, tool and resource
results, and prompts. Every kind reaches composition ([§3.1](../3-core-algorithms/3.1-working-set-composition/index.md)). An MCP prompt expansion is handled as
user input.

**Open:** a route that tells an MCP prompt expansion apart from a typed prompt. The budget
and overflow form of tool definitions are Open in [§3.1](../3-core-algorithms/3.1-working-set-composition/index.md).
