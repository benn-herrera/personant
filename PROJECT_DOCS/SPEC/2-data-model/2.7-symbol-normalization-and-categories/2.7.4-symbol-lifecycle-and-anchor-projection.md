#### 2.7.4 Symbol lifecycle and anchor projection

Format → ARCHITECTURE «Symbol lifecycle and anchor projection» (the projection rules). A thread's anchors are a
deterministic projection of its retained symbol history, re-derived every owner turn; no model call
is involved. A symbol that falls out of the projection is marked superseded and retained, so an
abandoned premise remains a findable recall handle; a symbol that was ever central is protected from
capacity trimming ([§2.3](../2.3-thread-file-format-threads-thr-id.md)) while the protected set fits the cap. The history is
bounded by `history.cap-per-thread` (40) and the projection by `anchor.projection-max` (8); flat
history never exceeds its cap; that it stays below the cap with a flat once-central count over a run, so protection never has to yield, is a [§9](../../9-measurement-and-validation-regime/index.md) sim obligation, not a static guarantee.
