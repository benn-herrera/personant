### 2.4 Symbol index schema (`symbols.jsonl`)

Unused → ARCHITECTURE.md «Storage and record formats». A derived inverse index from symbol to
threads (with which threads hold it as an anchor and which have superseded it, [§3.4](../3-core-algorithms/3.4-recall-matching/index.md)) is rebuilt from
canonical files on every index refresh, ordered most-recalled thread first; supersession state is
read only from the thread frontmatter.
