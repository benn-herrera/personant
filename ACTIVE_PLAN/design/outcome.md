### Outcome

The number of files tracked in the home, and so in each day's daily repository, stops growing with
thread length and with how many threads have ever retired. A thread's cold excerpts sit in one
per-thread file. Its warm excerpts stay loose files, as they are today. Every reader gets the same
bytes, in the same order, whichever form holds them. Per-turn commit cost then holds steady over a
multi-day run instead of rising with the career.
