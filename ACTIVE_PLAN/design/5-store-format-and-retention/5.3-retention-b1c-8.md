### 5.3 Retention (B1c, [§8](../8-barrier-step-b1c-and-crash-safety/index.md))

- **Entries kept:** entries with `turn > turnCount − ThreadTurnWindow`. Positions older than that
  can never be composed, because `ReadThreadBody` never assembles beyond the window.
- **Files kept:** for each kept entry, `files/<id>`, plus `files/<from>-<to>.diff` for each change
  with `diff:true`.
- **Files removed:** every other file under `files/`, and legacy `files.json`.
- **Resulting bound per thread:** (paths touched in the last 512 turns) × (current size + N diffs).
  The bound does not depend on edit count or on git. A blob shared by two paths survives while
  either entry names it.
