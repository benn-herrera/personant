### 5.3 Retention

Applied by barrier step B1c ([§8](../8-barrier-step-b1c-and-crash-safety/index.md)). `turnCount` is
the thread's spine `TurnCount`, the same counter an entry's `turn` records; `ThreadTurnWindow` is
512 (`internal/store/thread_io.go:36`).

- **Entries kept:** entries with `turn > turnCount − ThreadTurnWindow`. Positions older than that
  can never be composed, because the excerpt reader never assembles beyond the window.
- **Files kept:** for each kept entry, `files/<id>`, plus `files/<from>-<to>.diff` for each change
  with `diff:true`.
- **Files removed:** every other file under `files/`, and legacy `files.json`.
- **Resulting bound per thread:** (paths touched in the last 512 turns) × (current size + N diffs).
  The bound depends neither on edit count nor on git. A blob shared by two paths survives while
  either entry names it.
